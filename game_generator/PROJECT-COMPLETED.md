## 🤔 Preguntas Frecuentes

### ¿Necesito hacer algo más?

**No.** El PWA está 100% configurado. Solo:
1. `npm install` 
2. `npm run build`
3. `netlify deploy --prod`
4. ¡Instala en tu teléfono!

### ¿Puedo cambiar los iconos?

Sí. Edita `manifest.json` con tus iconos. Ver guía en PWA-SETUP.md.

### ¿Cómo actualizo la app?

Haz cambios → `git push` → Netlify redeploya automáticamente → Service Worker notifica.

### ¿Funciona en modo offline?

Sí. Assets se cachean automáticamente. La app funciona sin internet.

### ¿Qué pasa con la API key?

Se configura en variables de entorno de Netlify. Nunca se expone al cliente.

### ¿Puedo agregar notificaciones push?

Sí. El Service Worker está preparado. Ver PWA-SETUP.md para implementación.
